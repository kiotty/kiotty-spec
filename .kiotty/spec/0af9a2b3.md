## 시그니처
```c
KiottySpecStatus KiottySpec_Cursor_getMilestoneEntry(KiottySpecCursor *cursor, size_t index, const KiottySpecMilestoneEntry **out);  /* index 번째 마일스톤 포함 항목 */
```

## 사전조건
- cursor 는 원소가 MilestoneEntry 인 커서
- index < Cursor_count

## 사후조건
- *out 에 index 번째 원소 포인터

## 에러 코드
- index 범위 밖: InvalidArg
- 원소 종류가 다름: WrongCursorType
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *out 는 커서 소유, Cursor_end 전까지 유효. 해제하지 않는다
