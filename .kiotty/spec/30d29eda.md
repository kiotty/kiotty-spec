## 진술
사용자는 프로젝트 폴더를 한 번 초기화해 기록 저장소를 만든다. 작업용 DB 는 git 에서 제외되고, 원하면 커밋·병합 때 기록을 자동으로 주고받는 git 훅도 설치된다.

## 근거 시나리오
사용자가 Kiotty-Spec 을 처음 쓸 때 한 번 초기화한다. 예전 버전 도구로 만든 프로젝트를 새 버전 도구로 열어도 그대로 이어서 쓸 수 있어야 한다.

## 인수 조건
- 전제 조건: 처음 쓰는 폴더 / 행동: 초기화한다 / 기대 결과: 기록 저장소가 생기고, git 제외 목록에 작업용 DB 가 추가된다
- 전제 조건: 이미 초기화된 폴더 / 행동: 다시 초기화한다 / 기대 결과: 기존 기록이 유지되고 제외 목록에 같은 줄이 중복되지 않는다
- 전제 조건: git 저장소 / 행동: 훅 설치를 요청하며 초기화한다 / 기대 결과: 커밋 전에 기록을 내보내고, 병합·체크아웃 뒤에 기록을 다시 가져오는 훅이 설치된다
- 전제 조건: git 저장소가 아닌 폴더 / 행동: 훅 설치를 요청한다 / 기대 결과: git 저장소가 아니라는 이유로 거부된다
- 전제 조건: 이전 버전 도구로 만든 기록 / 행동: 새 버전 도구로 연다 / 기대 결과: 기록 구조가 자동으로 올라가고 내용은 그대로다
