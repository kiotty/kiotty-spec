## 진술
모든 시스템·E2E 테스트가 1:1 로 있고 마지막 결과가 통과이며, 코드 검사 위반이 없고, 열린 변경 요청이 없으면 사용자가 RELEASE 체크포인트를 선언할 수 있다. 그 뒤로는 유지보수 단계가 된다.

## 근거 시나리오
정의서 "최초 개발 완료와 그 이후", R-10. AI 는 선언 전에 조건을 확인해 무엇이 남았는지 보고한다.

## 인수 조건
- 전제 조건: 시스템 테스트 하나의 마지막 결과가 실패 / 행동: RELEASE 조건을 확인한다 / 기대 결과: 불가, 그 테스트가 목록에
- 전제 조건: 개발 규칙 하나의 마지막 검사가 위반 / 행동: 확인 / 기대 결과: 불가
- 전제 조건: 열린 변경 요청 1 건 / 행동: 확인 / 기대 결과: 불가
- 전제 조건: 조건 모두 만족 / 행동: AI 가 선언을 시도 / 기대 결과: 사용자만 할 수 있다는 이유로 거부
- 전제 조건: 조건 모두 만족 / 행동: 사용자가 선언 / 기대 결과: 확정된 RELEASE 체크포인트, 현재 위치의 다음 할 일은 "유지보수"
