## 시그니처
```c
KiottySpecStatus KiottySpec_init(KiottySpec *db, const char *projectName, bool installGitHooks);  /* 프로젝트 메타데이터를 만들고 선택적으로 pre-commit/post-merge 훅을 설치한다 */
```

## 사전조건
- installGitHooks=true 면 projectRoot 가 git 저장소 (.git 디렉토리)

## 사후조건
- 프로젝트 메타데이터 기록, .gitignore 에 작업용 DB 줄을 중복 없이 추가
- installGitHooks 면 pre-commit(내보내기)·post-merge(가져오기) 훅 설치
- 다시 불러도 기존 기록 유지

## 에러 코드
- git 저장소가 아닌데 훅 설치: Precondition
- 파일 쓰기 실패: Io
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
