## 시그니처
```c
KiottySpecStatus KiottySpec_Import_markdown(KiottySpec *db, KiottySpecActor actor, KiottySpecItemKind kind, const char *markdown, KiottySpecCursor **outCreatedIds);  /* 정해진 틀의 Markdown 을 항목으로 가져온다 (getId) */
```

## 사전조건
- markdown 은 "## [분류] 제목" 절 구성

## 사후조건
- 절마다 항목 하나를 kind 로 만들고 *outCreatedIds 에 만든 ID (getId)

## 에러 코드
- 가져올 절이 없음, 맞지 않는 분류: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- *outCreatedIds 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
