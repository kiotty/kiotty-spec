## 시그니처
```c
KiottySpecStatus KiottySpec_Result_listBegin(KiottySpec *db, const char *targetId, KiottySpecCursor **outCursor);  /* 대상의 결과 이력 (getResult) */
```

## 사전조건
- 없음

## 사후조건
- 대상의 결과 이력 커서 (getResult)

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
