## 시그니처
```c
KiottySpecStatus KiottySpec_Context_forItem(KiottySpec *db, const char *itemId, int32_t depth, size_t maxBytes, char **outMarkdown);  /* 항목과 상·하류 연결 항목, 관련 결정 줄 */
```

## 사전조건
- itemId 는 현재 항목

## 사후조건
- 항목 본문, depth 까지의 상·하류 항목, 관련 결정 줄을 Markdown 으로

## 에러 코드
- 없는 항목: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outMarkdown 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
