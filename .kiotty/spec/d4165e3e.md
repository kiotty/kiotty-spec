## 개요
함수 5 개를 묶은 개념 단위. 함수별 계약은 하위 항목에 있고, 여기에는 묶음 공통의 타입과 규약을 둔다.

## 하위 함수
- UI-074 KiottySpec_Milestone_setEntryState
- UI-075 KiottySpec_Milestone_entriesBegin
- UI-076 KiottySpec_Milestone_uncoveredBegin
- UI-077 KiottySpec_Milestone_next
- UI-078 KiottySpec_Milestone_progress

## 시그니처
```c
typedef enum KiottySpecImplState {
    KiottySpecImplState_NotImplemented = 1,  /* 미구현 */
    KiottySpecImplState_NeedsChange,         /* 변경 필요 (구현 완료 뒤 설계가 바뀜, R-6) */
    KiottySpecImplState_Implemented          /* 구현 완료 */
} KiottySpecImplState;

typedef struct KiottySpecMilestoneEntry {
    const char *milestoneId;                 /* 마일스톤 */
    const char *itemId;                      /* 포함된 설계 항목 또는 유닛 테스트 */
    KiottySpecImplState state;               /* 미구현 / 변경 필요 / 구현 완료 (계산 값) */
    const char *implementedCp;               /* 구현 완료로 기록된 체크포인트 (없으면 NULL) */
} KiottySpecMilestoneEntry;
```

## 사전조건
- milestoneId 는 마일스톤, itemId 는 그 마일스톤이 포함한다 링크로 가리키는 설계·유닛 테스트

## 사후조건
- setEntryState(Implemented): 현재 체크포인트를 implementedCp 로 기록
- entries 의 state 는 계산 값: 구현 완료 뒤 설계가 바뀌면(같은 라운드 포함) NeedsChange (R-6)
- next: 미구현·변경 필요가 남은 첫 마일스톤, 없으면 NotFound
- uncovered: 어느 마일스톤에도 없는 설계·유닛 테스트 (R-5)

## 에러 코드
- 마일스톤이 아니거나 포함하지 않은 항목: InvalidArg
- 없는 ID: NotFound
- NULL 핸들·NULL 필수 인자는 InvalidArg, 상세는 KiottySpec_lastError

## 소유권
- next 의 *outMilestoneId 는 호출자가 KiottySpec_free
- 커서는 Cursor_end
