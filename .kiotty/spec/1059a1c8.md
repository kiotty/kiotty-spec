## 시그니처
```c
KiottySpecStatus KiottySpec_setPolicy(KiottySpec *db, const char *key, const char *value);  /* 정책 설정. 예) decision_max_line=200, decision_max_concerns=8 */
```

## 사전조건
- key 는 decision_max_line 또는 decision_max_concerns (다른 키도 저장되지만 쓰이지 않음)

## 사후조건
- 정책 값을 저장한다. 이후 결정 기록 검사가 새 한도를 쓴다

## 에러 코드
- 빈 key: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
