## 시그니처
```c
KiottySpecStatus KiottySpec_ChangeRequest_listBegin(KiottySpec *db, KiottySpecChangeState stateOr0, KiottySpecCursor **outCursor);  /* 상태별 변경 요청 (getChangeRequest) */
```

## 사전조건
- stateOr0 은 0(전체) 또는 상태

## 사후조건
- 변경 요청 커서 (getChangeRequest)

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
