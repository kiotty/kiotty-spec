## 시그니처
```c
KiottySpecStatus KiottySpec_Item_childrenBegin(KiottySpec *db, const char *itemId, bool recursive, KiottySpecCursor **outCursor);  /* 하위 항목 열거 (getItem) */
```

## 사전조건
- itemId 는 현재 항목

## 사후조건
- 하위 항목 커서 (getItem), seq 순. recursive 면 자손 전부

## 에러 코드
- 없는 항목: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
