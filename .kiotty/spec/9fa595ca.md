## 시그니처
```c
KiottySpecStatus KiottySpec_Result_failedBegin(KiottySpec *db, KiottySpecItemKind kindOr0, KiottySpecCursor **outCursor);  /* 마지막 결과가 FAIL 인 테스트 또는 개발 규칙 (getItem) */
```

## 사전조건
- kindOr0 은 0(전체), 테스트 종류 또는 Rule

## 사후조건
- 마지막 결과가 FAIL 인 테스트·규칙 커서 (getItem)

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
