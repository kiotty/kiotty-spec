## 시그니처
```c
KiottySpecStatus KiottySpec_Checkpoint_current(KiottySpec *db, KiottySpecCheckpoint **out);  /* 가장 최근 체크포인트 (미확정일 수 있음) */
```

## 사전조건
- 없음

## 사후조건
- *out 에 가장 최근 체크포인트 (미확정일 수 있음)

## 에러 코드
- 체크포인트가 아직 없음: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *out 는 호출자가 KiottySpec_free
