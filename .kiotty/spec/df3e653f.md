## 시그니처
```c
KiottySpecStatus KiottySpec_Link_upstreamBegin(KiottySpec *db, const char *id, int32_t depth, KiottySpecCursor **outCursor);  /* 요구사항 방향으로 깊이 제한 내 연결된 항목·파일 ID (getId). depth 0 은 무제한. "왜 이 코드가 있는가" */
```

## 사전조건
- depth 0 은 무제한

## 사후조건
- 요구사항 쪽으로 depth 까지 연결된 항목·파일 ID 커서 (getId). "왜 있는가"

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
