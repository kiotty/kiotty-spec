## 시그니처
```c
KiottySpecStatus KiottySpec_Milestone_entriesBegin(KiottySpec *db, const char *milestoneId, KiottySpecCursor **outCursor);  /* 포함 항목과 계산된 상태 (getMilestoneEntry, R-6) */
```

## 사전조건
- milestoneId 는 마일스톤

## 사후조건
- 포함 항목과 계산된 상태 커서 (getMilestoneEntry). 구현 완료 뒤 설계가 바뀌면(같은 라운드 포함) NeedsChange (R-6)

## 에러 코드
- 마일스톤이 아님: InvalidArg
- 없는 ID: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
