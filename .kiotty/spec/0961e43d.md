## 규칙
공개 함수 KiottySpec_<그룹>_<동사>(동사 camelCase), 타입 KiottySpec<이름>, 열거 상수 <타입 이름>_<값>, 목록을 돌려주는 함수는 ...Begin 으로 끝나고 커서를 돌려준다. 내부 C++ 는 namespace kiotty::core / kiotty::base, 타입 PascalCase, 함수 camelCase, 멤버 변수는 끝에 _ (공개 멤버 모듈은 예외), 상수 k 접두어.

## 이유
헤더 머리말의 규칙을 내부까지 이어서, 이름만으로 공개/내부와 소유권을 알 수 있게 한다.

## 검사 방법
헤더의 함수·타입·열거자 이름을 정규식으로, 내부 클래스·함수·멤버 이름을 clang-tidy readability-identifier-naming 또는 grep 으로 검사
