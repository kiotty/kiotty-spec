## 개요
함수 11 개를 묶은 개념 단위. 함수별 계약은 하위 항목에 있고, 여기에는 묶음 공통의 타입과 규약을 둔다.

## 하위 함수
- UI-025 KiottySpec_Cursor_count
- UI-026 KiottySpec_Cursor_getItem
- UI-027 KiottySpec_Cursor_getLink
- UI-028 KiottySpec_Cursor_getFile
- UI-029 KiottySpec_Cursor_getCheckpoint
- UI-030 KiottySpec_Cursor_getChangeRequest
- UI-031 KiottySpec_Cursor_getResult
- UI-032 KiottySpec_Cursor_getMilestoneEntry
- UI-033 KiottySpec_Cursor_getStepRun
- UI-034 KiottySpec_Cursor_getId
- UI-035 KiottySpec_Cursor_end

## 시그니처
```c
typedef struct KiottySpecCursor KiottySpecCursor;  /* 목록 커서. ...Begin 이 만들고 Cursor_end 가 정리한다 */
```

## 사전조건
- cursor 는 ...Begin 함수가 만든 것
- index < Cursor_count

## 사후조건
- get<타입> 은 원소 포인터를 out 에 쓴다. getId 는 모든 커서에서 원소의 대표 ID 를 준다
- Cursor_end 뒤 cursor 와 원소 포인터는 모두 무효

## 에러 코드
- index 범위 밖은 InvalidArg
- 원소 종류와 다른 get<타입> 은 WrongCursorType
- NULL 핸들·NULL 필수 인자는 InvalidArg, 상세는 KiottySpec_lastError

## 소유권
- 원소 포인터와 그 문자열은 커서 소유, Cursor_end 전까지 유효. KiottySpec_free 로 해제하지 않는다
- Cursor_end(NULL) 은 아무것도 하지 않는다
