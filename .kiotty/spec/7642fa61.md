## 시그니처
```c
KiottySpecStatus KiottySpec_Check_all(KiottySpec *db, char **outReport);  /* 위 검사와 마일스톤 포함, 결정 기록 검사를 모두 돌려 Markdown 보고서로 */
```

## 사전조건
- 없음

## 사후조건
- *outReport 에 위 검사 + 마일스톤 포함(R-5) + 결정 기록 검사를 종류별 개수·목록 Markdown 으로

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outReport 는 호출자가 KiottySpec_free
