## 시그니처
```c
KiottySpecStatus KiottySpec_Cursor_getId(KiottySpecCursor *cursor, size_t index, const char **out);  /* index 번째 원소의 ID. 모든 커서에서 동작한다 (링크는 fromId, 결과는 targetId, 마일스톤 포함 항목은 itemId) */
```

## 사전조건
- cursor 는 ...Begin 이 만든 것
- index < Cursor_count

## 사후조건
- *out 에 원소의 대표 ID: 링크는 fromId, 결과는 targetId, 마일스톤 포함 항목은 itemId. 모든 커서에서 동작

## 에러 코드
- index 범위 밖: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *out 는 커서 소유, Cursor_end 전까지 유효. 해제하지 않는다
- 입력 문자열은 호출 동안만 읽는다
