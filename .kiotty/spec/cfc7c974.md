## 시그니처
```c
KiottySpecStatus KiottySpec_File_register(KiottySpec *db, KiottySpecActor actor, KiottySpecFileRole role, const char *path, char **outId);  /* 파일을 등록하고 해시를 기록한다 */
```

## 사전조건
- path 는 프로젝트 안 파일 (절대 경로면 루트 기준 상대 경로로 정규화)

## 사후조건
- FILE-### 발급과 내용 해시 기록. 이미 등록된 경로면 다시 해시하고 기존 ID. 없는 파일은 해시 "missing"
- *outId 에 ID

## 에러 코드
- 빈 경로: InvalidArg
- 같은 경로가 다른 역할로 등록됨: Conflict
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- *outId 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
