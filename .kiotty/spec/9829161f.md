## 시그니처
```c
KiottySpecStatus KiottySpec_File_changedSinceBegin(KiottySpec *db, const char *cpId, KiottySpecCursor **outCursor);  /* 체크포인트 이후 해시가 바뀐 파일 (getFile) */
```

## 사전조건
- cpId 는 존재하는 체크포인트

## 사후조건
- 그 체크포인트 이후 해시가 바뀐 파일 커서 (getFile)

## 에러 코드
- 없는 CP: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
