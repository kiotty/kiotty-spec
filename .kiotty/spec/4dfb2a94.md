## 시그니처
```c
KiottySpecStatus KiottySpec_Result_summary(KiottySpec *db, KiottySpecItemKind kind, size_t *outTotal, size_t *outPass, size_t *outFail, size_t *outNotRun);  /* 종류별 통과·실패·미실행 집계 */
```

## 사전조건
- kind 는 테스트 종류 또는 Rule

## 사후조건
- *outTotal·*outPass·*outFail·*outNotRun

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- 돌려받아 해제할 메모리 없음 (out 값은 호출자 변수에 복사)
