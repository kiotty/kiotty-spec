## 개요
함수 7 개를 묶은 개념 단위. 함수별 계약은 하위 항목에 있고, 여기에는 묶음 공통의 타입과 규약을 둔다.

## 하위 함수
- UI-079 KiottySpec_File_register
- UI-080 KiottySpec_File_get
- UI-081 KiottySpec_File_byPath
- UI-082 KiottySpec_File_rescan
- UI-083 KiottySpec_File_listBegin
- UI-084 KiottySpec_File_changedSinceBegin
- UI-085 KiottySpec_File_scanGuiDraft

## 시그니처
```c
typedef enum KiottySpecFileRole {
    KiottySpecFileRole_GuiDraft = 1,         /* GUI 초안 html */
    KiottySpecFileRole_CHeader,              /* C/C++ 헤더 */
    KiottySpecFileRole_Source                /* 소스 코드 */
} KiottySpecFileRole;

typedef struct KiottySpecFile {
    const char *id;                          /* "FILE-015" */
    KiottySpecFileRole role;                 /* GUI 초안 / 헤더 / 소스 */
    const char *path;                        /* 프로젝트 루트 기준 경로 */
    const char *hash;                        /* 마지막 기록 해시 */
    const char *cpFrom;                      /* 이 해시가 기록된 체크포인트 */
} KiottySpecFile;
```

## 사전조건
- path 는 프로젝트 안의 파일 (루트 기준 상대 경로로 정규화해 저장)
- scanGuiDraft 의 fileId 는 GuiDraft 역할

## 사후조건
- register: FILE-### 발급과 내용 해시 기록. 이미 등록된 경로면 다시 해시하고 기존 ID. 없는 파일은 해시 "missing"
- rescan: 해시를 다시 계산해 기록하고 바뀌었는지 알려 준다
- changedSinceBegin: 그 체크포인트 이후 해시가 바뀐 파일
- scanGuiDraft: html 의 data-ks-id 중 DB 에 없는 ID 와, html 에 없는 GUI 뷰 항목

## 에러 코드
- 빈 경로: InvalidArg
- 같은 경로가 다른 역할로 등록됨: Conflict
- 없는 FILE·CP: NotFound
- NULL 핸들·NULL 필수 인자는 InvalidArg, 상세는 KiottySpec_lastError

## 소유권
- register 의 *outId, get·byPath 의 *out 은 호출자가 KiottySpec_free
- 커서는 Cursor_end
