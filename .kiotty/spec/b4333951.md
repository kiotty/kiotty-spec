## 시그니처
```c
KiottySpecStatus KiottySpec_Decision_check(KiottySpec *db, KiottySpecDecisionKind kind, char **outReport);  /* 사라진 항목을 가리키는 줄, 길이 초과 줄을 보고 */
```

## 사전조건
- kind 는 결정 기록 종류

## 사후조건
- *outReport 에 사라진 항목을 가리키는 줄과 한도 초과 줄. 기록은 그대로

## 에러 코드
- 모르는 kind: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outReport 는 호출자가 KiottySpec_free
