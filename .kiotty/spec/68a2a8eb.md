## 시그니처
```c
KiottySpecStatus KiottySpec_Link_impactBegin(KiottySpec *db, const char *sinceCpId, KiottySpecCursor **outCursor);  /* 체크포인트 이후 바뀐 항목과 링크된 영향 항목 (getItem). 각 단계의 "다시 볼 것" */
```

## 사전조건
- sinceCpId 는 존재하는 체크포인트

## 사후조건
- 그 체크포인트 이후 바뀐 항목과 링크로 연결된 영향 항목 커서 (getItem)

## 에러 코드
- 없는 CP: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
