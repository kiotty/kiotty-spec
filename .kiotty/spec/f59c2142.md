## 시그니처
```c
KiottySpecStatus KiottySpec_Export_markdown(KiottySpec *db, KiottySpecItemKind kind, char **outMarkdown);  /* 종류별 문서(요구사항서, 설계서, 테스트 계획서, 개발 계획서) 생성 */
```

## 사전조건
- kind 는 항목 종류

## 사후조건
- *outMarkdown 에 종류별 문서. 항목마다 "ID [분류] 제목", 연결 요약, 본문

## 에러 코드
- 모르는 kind: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outMarkdown 는 호출자가 KiottySpec_free
