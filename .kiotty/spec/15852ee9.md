## 책임
명령줄 토큰에서 명령을 찾고, --root/환경변수/위쪽 .kiotty 탐색으로 프로젝트 루트를, --actor/환경변수로 actor 를 정해 DB 를 열고 실행한다. 실패는 stderr 'error: <상태>: <메시지>' 와 종료 코드 1(사용법 2). Windows 는 UTF-8 콘솔.

## 모듈 인터페이스
```cpp
int run(std::vector<std::string> tokens);   // 명령 실행, 종료 코드
const Command *findCommand(const std::vector<std::string> &tokens, size_t &consumed);
std::string findRoot(const Arguments &args);   // --root > KIOTTY_SPEC_ROOT > 위쪽 .kiotty
KiottySpecActor findActor(const Arguments &args); // --actor > KIOTTY_SPEC_ACTOR > ai
int wmain(int argc, wchar_t **argv);   // Windows: UTF-16 인자 -> UTF-8, 콘솔 UTF-8
int main(int argc, char **argv);       // 그 밖
```
