## 시그니처
```c
KiottySpecStatus KiottySpec_File_rescan(KiottySpec *db, KiottySpecActor actor, const char *fileId, bool *outChanged);  /* 해시를 다시 계산해 기록하고 바뀌었는지 알려준다 */
```

## 사전조건
- fileId 는 등록된 파일

## 사후조건
- 해시를 다시 계산해 기록하고 *outChanged 에 바뀌었는지

## 에러 코드
- 없는 FILE: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음 (out 값은 호출자 변수에 복사)
- 입력 문자열은 호출 동안만 읽는다
