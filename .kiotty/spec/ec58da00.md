## 규칙
외부 라이브러리는 SQLite amalgamation, nlohmann/json, md4c 셋뿐이고, 버전을 고정한 URL 로 FetchContent 해서 자체 정적 타깃으로 빌드한다. 다른 라이브러리를 추가하려면 먼저 이 규칙과 환경 요구사항을 바꾼다. 의존성은 kiotty_spec 에 PRIVATE 로 링크한다 (공개 헤더에 노출 금지).

## 이유
빌드를 재현 가능하게 하고, 공개 C 인터페이스가 외부 라이브러리 타입에 묶이지 않게 한다.

## 검사 방법
CMakeLists.txt 의 FetchContent_Declare 목록과 URL 버전 확인, include/kiotty_spec.h 에 sqlite3·nlohmann·md4c 가 나오지 않는지 grep
