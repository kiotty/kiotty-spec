## 시그니처
```c
KiottySpecStatus KiottySpec_Checkpoint_confirm(KiottySpec *db, KiottySpecActor actor, const char *cpId);  /* 체크포인트를 확정한다. User 만 가능, 단계별 확정 조건 미충족 시 Precondition (R-2 ~ R-5) */
```

## 사전조건
- actor 는 User (R-2)
- cpId 는 찍힌 체크포인트

## 사후조건
- 단계별 확정 조건(Step 1·2 R-4, Step 6 R-5, Step 8·10 R-3)을 만족하면 확정. 이미 확정이면 그대로 Ok
- 확정된 내용은 이후 바뀌지 않는다 (R-1)

## 에러 코드
- Ai: Permission
- 조건 미충족: Precondition (사유는 lastError)
- PENDING 지정·ID 형식 오류: InvalidArg
- 없는 CP: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
