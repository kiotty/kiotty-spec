## 시그니처
```c
KiottySpecStatus KiottySpec_Checkpoint_releaseCheck(KiottySpec *db, bool *outOk, char **outReport);  /* 지금 RELEASE 할 수 있는지와 그 이유 (R-10) */
```

## 사전조건
- 없음

## 사후조건
- *outOk 에 R-10 만족 여부, *outReport 에 남은 목록 (1:1 위반, PASS 아닌 테스트, 위반 규칙, 열린 CR). 기록은 그대로

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outReport 는 호출자가 KiottySpec_free
