## 시그니처
```c
KiottySpecStatus KiottySpec_Item_create(KiottySpec *db, KiottySpecActor actor, KiottySpecItemKind kind, KiottySpecItemCategory category, const char *parentIdOrNull, const char *title, const char *body, char **outId);  /* 항목을 만들고 ID 를 발급한다 */
```

## 사전조건
- category 는 kind 에 맞는 분류 (테스트·마일스톤은 None)
- title 은 비어 있지 않음
- parentIdOrNull 은 NULL 또는 현재 항목

## 사후조건
- 종류별 접두어 + 3 자리 번호를 발급해 현재(미확정) 라운드에 쓴다
- *outId 에 ID
- 같은 종류·제목이 있어도 새로 만든다 (경고 없음 — 261104_01 #3)

## 에러 코드
- kind 와 맞지 않는 category, 빈 title: InvalidArg
- 없는 상위: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- *outId 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
