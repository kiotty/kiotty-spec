## 시그니처
```c
KiottySpecStatus KiottySpec_Link_matrix(KiottySpec *db, KiottySpecItemKind rowKind, KiottySpecItemKind colKind, char **outCsv);  /* 두 종류 간 추적 매트릭스 CSV */
```

## 사전조건
- rowKind·colKind 는 항목 종류

## 사후조건
- *outCsv 에 행 종류 × 열 종류 추적표, 연결된 칸은 x

## 에러 코드
- 모르는 종류: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCsv 는 호출자가 KiottySpec_free
