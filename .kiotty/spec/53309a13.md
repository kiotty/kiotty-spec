## 시그니처
```c
KiottySpecStatus KiottySpec_Checkpoint_release(KiottySpec *db, KiottySpecActor actor, const char *note, char **outId);  /* RELEASE 체크포인트를 만들고 확정한다. 조건 미충족 시 Precondition (R-10) */
```

## 사전조건
- actor 는 User (R-2)
- R-10 만족

## 사후조건
- RELEASE 목적의 체크포인트를 만들고 확정한다. 이후 다음 할 일은 유지보수
- *outId 에 ID

## 에러 코드
- Ai: Permission
- R-10 미충족: Precondition (남은 목록은 lastError)
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- *outId 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
