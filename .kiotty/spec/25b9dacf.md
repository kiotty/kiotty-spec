## 진술
AI 는 인터페이스 파일(GUI 초안, C 헤더)과 소스 파일을 등록해 두고 내용이 바뀌었는지 알 수 있으며, GUI 초안이 가리키는 화면과 기록의 화면 항목이 서로 맞는지 확인할 수 있다.

## 근거 시나리오
Step 3 에서 헤더를, Step 7 에서 소스 파일을 등록한다. 다음 라운드에 AI 는 "지난 기준 이후 바뀐 파일" 을 받아 그것만 다시 본다. GUI 초안을 고친 뒤에는 초안의 화면 표시와 기록의 화면 항목이 어긋나지 않았는지 확인한다.

## 인수 조건
- 전제 조건: 프로젝트 안의 소스 파일 / 행동: 등록한다 / 기대 결과: FILE-### 번호가 붙고 그때의 내용이 기록된다
- 전제 조건: 등록 뒤 파일을 고쳤다 / 행동: 다시 확인한다 / 기대 결과: 바뀌었다는 답과 새 내용 기록
- 전제 조건: 어떤 체크포인트 이후 바뀐 파일 / 행동: 그 이후 바뀐 파일을 묻는다 / 기대 결과: 그 파일
- 전제 조건: GUI 초안은 UI-009 를, 기록은 UI-007 화면만 가리킨다 / 행동: GUI 초안을 확인한다 / 기대 결과: 초안에만 있는 UI-009 와 기록에만 있는 UI-007
