## 시그니처
```c
KiottySpecStatus KiottySpec_Result_record(KiottySpec *db, KiottySpecActor actor, const char *targetId, KiottySpecTestResult result, const char *log);  /* 테스트 또는 (대상이 개발 규칙이면) 코드 검사 결과를 기록한다 */
```

## 사전조건
- targetId 는 유닛·시스템·E2E 테스트 또는 (코드 검사면) 개발 규칙
- log 는 NULL 가능

## 사후조건
- 대상별 이력에 PASS/FAIL 과 log 를 현재 체크포인트로 쌓는다

## 에러 코드
- 테스트·규칙이 아닌 대상, 잘못된 result: InvalidArg
- 없는 ID: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
