## 진술
사용자와 AI 는 프로젝트 안 어느 폴더에서 명령을 실행해도 같은 프로젝트 기록을 다루고, 결과를 사람과 AI(스크립트)가 모두 다루기 쉬운 형태로 받는다.

## 근거 시나리오
AI 가 소스 폴더 깊은 곳에서 작업하다 기록을 묻는다. 기본적으로 AI 로 간주되어 확정 같은 사용자 권한 작업은 못 하고, 사용자가 확정할 때는 사용자임을 밝히고 실행한다. 스크립트는 실패를 종료 코드로 알아챈다.

## 인수 조건
- 전제 조건: 하위 폴더에서 실행 / 행동: 현재 위치를 묻는다 / 기대 결과: 가장 가까운 상위 프로젝트의 기록. 프로젝트 경로를 직접 지정하면 그것이 우선
- 전제 조건: 실행한 사람을 밝히지 않음 / 행동: 확정을 시도한다 / 기대 결과: AI 로 간주되어 거부된다. 사용자로 밝히면 된다
- 전제 조건: 항목 목록 조회 / 행동: 실행 / 기대 결과: 스크립트가 읽는 JSON. 현재 위치나 문서는 사람이 읽는 Markdown
- 전제 조건: 실패하는 명령 / 행동: 실행 / 기대 결과: 실패 이유 한 줄과 실패 종료 코드
- 전제 조건: 긴 본문 / 행동: 인자, 파일, 표준 입력 중 하나로 넣는다 / 기대 결과: 세 방식 모두 같은 본문으로 저장
- 전제 조건: Windows, 한글 제목 / 행동: 저장 후 조회 / 기대 결과: 깨지지 않고 그대로 보인다
