## 사전조건
- dir 은 프로젝트 안 디렉토리 (NULL·빈 문자열이면 .kiotty/spec)
- Import_markdown 의 문서는 "## [분류] 제목" 절 구성

## 사후조건
- Export_jsonl: 테이블별 jsonl 을 ID 순으로, 같은 기록이면 같은 바이트 (REQ-024). pre-commit 훅이 부른다
- Import_jsonl(merge=false): jsonl 로 DB 를 다시 만든다. post-merge 훅이 부른다
- Import_jsonl(merge=true): 같은 ID 는 기존 행 유지 후 보고 (헤더 주석과 다름 — 261104_02 #4, 병합은 요구하지 않음)
- Export_markdown: 종류별 문서, traceReport: 추적표 + 검사 보고서. Import_markdown: 절마다 항목 하나, 만든 ID 커서

## 에러 코드
- 파일 입출력 실패: Io
- jsonl 파싱 실패: InvalidArg (파일·행 번호)
- 가져올 "## 제목" 절이 없음: InvalidArg
- merge 의 ID 충돌은 실패가 아니라 outConflictReport 로 보고
- NULL 핸들·NULL 필수 인자는 InvalidArg, 상세는 KiottySpec_lastError

## 소유권
- Markdown·보고서는 호출자가 KiottySpec_free
- Import_markdown 의 커서는 Cursor_end
