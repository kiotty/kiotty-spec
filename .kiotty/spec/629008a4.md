## 시그니처
```c
KiottySpecStatus KiottySpec_Link_listBegin(KiottySpec *db, const char *id, KiottySpecDirection dir, KiottySpecLinkType typeOr0, KiottySpecCursor **outCursor);  /* 항목·파일에 걸린 링크 (getLink) */
```

## 사전조건
- typeOr0 은 0(전체) 또는 링크 종류

## 사후조건
- 그 ID 에 걸린 링크 커서 (getLink), dir 방향만

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
