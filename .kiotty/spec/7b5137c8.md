## 시그니처
```c
KiottySpecStatus KiottySpec_Check_unlinkedBegin(KiottySpec *db, KiottySpecItemKind kind, KiottySpecCursor **outCursor);  /* 링크가 하나도 없는 항목 (getItem) */
```

## 사전조건
- kind 는 항목 종류

## 사후조건
- 링크가 하나도 없는 그 종류의 항목 커서 (getItem)

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
