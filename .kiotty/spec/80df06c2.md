## 규칙
include/kiotty_spec.h 가 유일한 공개 인터페이스다. src/kiotty_spec.cpp 는 인자 검사와 예외→상태 코드 변환만 하고 일은 implementation/base 에 맡긴다. base 는 도메인 모듈(체크포인트·항목·링크·검사·맥락 등), core 는 도메인을 모르는 기반(DB, 커서, 텍스트, Markdown, 이름 표)이다. 의존은 경계 → base → core 한 방향이다.

## 이유
C 계약을 고정한 채 내부를 바꿀 수 있고, core 를 다른 도메인 규칙 없이 재사용·테스트할 수 있다.

## 검사 방법
core/ 의 #include 에 implementation/base 가 없는지, base 가 kiotty_spec.cpp 의 내용을 참조하지 않는지 grep
