## 시그니처
```c
KiottySpecStatus KiottySpec_Decision_rewrite(KiottySpec *db, KiottySpecActor actor, KiottySpecDecisionKind kind, const char *markdown);  /* 결정 기록을 통째로 다시 쓴다. 줄 길이·관심사 수 초과면 InvalidArg (R-7) */
```

## 사전조건
- 줄마다 "- ID · 관심사 : 결정 (이유) [기각: …]"

## 사후조건
- 종류의 결정 기록을 통째로 바꿔 현재 라운드에 쓴다. 이전 시점은 그대로

## 에러 코드
- 한 줄이 decision_max_line(기본 200 자) 초과, 항목 하나의 관심사가 decision_max_concerns(기본 8) 초과: InvalidArg (R-7, 어느 줄인지)
- 모르는 kind: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
