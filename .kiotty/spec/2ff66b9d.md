## 내용
| 넘기는 것 | 만드는 곳 | 해제 |
| --- | --- | --- |
| 단일 레코드 (*out 구조체) | core::pack* — 구조체와 문자열을 malloc 한 덩어리로 | 호출자 KiottySpec_free 한 번 |
| 문자열 (char **) | core::duplicateString (malloc) | 호출자 KiottySpec_free |
| 커서 | 경계가 new, 원소는 unique_ptr 상자(레코드 + C 뷰) | 호출자 Cursor_end (원소 포인터도 함께 무효) |
| 커서 원소 (const X *) | 커서 안의 상자 | 해제하지 않음. Cursor_end 까지 유효 |
| 핸들 KiottySpec | KiottySpec_open (new) | KiottySpec_close |
| 입력 문자열 | 호출자 | 호출 동안만 빌림, 복사해 보관 |

- 내부는 std::string·unique_ptr 로 소유하고 raw new/delete 를 쓰지 않는다 (RULE-008)
- 실패하면 *out 은 건드리지 않거나 NULL. 부분 할당은 경계 안에서 정리한다
- lastError 문자열은 스레드별이며 다음 호출 전까지 유효, 해제하지 않는다
