## 시그니처
```c
KiottySpecStatus KiottySpec_enumParse(const char *enumType, const char *name, int *outValue);  /* 이름을 열거값으로. enumType: ItemKind, ItemCategory, FileRole, LinkType, Direction, ChangeSource, ChangeState, ImplState, TestResult, Scope, DecisionKind, CheckpointPurpose, Actor */
```

## 사전조건
- enumType 은 헤더 주석의 13 개 이름 중 하나, name 은 영문 이름

## 사후조건
- *outValue 에 열거값

## 에러 코드
- 모르는 enumType·name: InvalidArg (받을 수 있는 값 목록은 메시지에 없음 — 261104_01 #2)
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- 돌려받아 해제할 메모리 없음 (out 값은 호출자 변수에 복사)
- 입력 문자열은 호출 동안만 읽는다
