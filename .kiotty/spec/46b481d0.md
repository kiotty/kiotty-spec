## 개요
함수 2 개를 묶은 개념 단위. 함수별 계약은 하위 항목에 있고, 여기에는 묶음 공통의 타입과 규약을 둔다.

## 하위 함수
- UI-092 KiottySpec_Link_impactBegin
- UI-093 KiottySpec_Link_scopeOf

## 시그니처
```c
typedef enum KiottySpecScope {
    KiottySpecScope_IntraModule = 1,         /* 모듈 내: 다른 모듈에 닿지 않음 → Step 7 에서 바로 수정 */
    KiottySpecScope_InterModule              /* 모듈 간: 다른 모듈에 닿음 → 변경 요청 필요 */
} KiottySpecScope;
```

## 사전조건
- impact 의 sinceCpId 는 존재하는 체크포인트
- scopeOf 의 대상은 설계 항목 또는 소스 파일

## 사후조건
- impact: 그 체크포인트 이후 바뀐 항목과 링크로 연결된 영향 항목
- scopeOf: 의존한다 링크로 다른 모듈에 닿으면 InterModule 과 닿는 모듈, 아니면 IntraModule

## 에러 코드
- 없는 CP·ID: NotFound
- 설계·소스 파일이 아닌 대상: InvalidArg
- NULL 핸들·NULL 필수 인자는 InvalidArg, 상세는 KiottySpec_lastError

## 소유권
- 커서는 Cursor_end
