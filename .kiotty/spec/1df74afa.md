## 진술
AI 는 항목과 파일을 정의서 3 절의 관계(만족시킨다, 검증한다, 구현한다, 포함한다, 의존한다)로만 연결할 수 있고, 정의되지 않은 연결은 거부된다.

## 근거 시나리오
Step 3 에서 "인터페이스가 기능 요구사항을 만족시킨다", Step 5 에서 "유닛 테스트가 설계를 검증한다", Step 7 에서 "소스 파일이 설계를 구현한다" 로 연결한다. 실수로 엉뚱한 쌍을 연결하면 바로 알려 준다.

## 인수 조건
- 전제 조건: 외부 인터페이스와 기능 요구사항 / 행동: "만족시킨다" 로 연결 / 기대 결과: 연결된다
- 전제 조건: 외부 인터페이스와 품질 요구사항 / 행동: "만족시킨다" 로 연결 / 기대 결과: 거부 (인터페이스는 기능 요구사항만 만족시킨다)
- 전제 조건: 동작 흐름 설계와 모듈 설계 / 행동: "의존한다" 로 연결 / 기대 결과: 거부 (의존은 모듈 사이만)
- 전제 조건: 소스 파일과 외부 인터페이스 / 행동: "구현한다" 로 연결 / 기대 결과: 거부 (소스는 설계를, 헤더·GUI 초안은 인터페이스를 구현한다)
- 전제 조건: 연결이 있음 / 행동: 끊는다 / 기대 결과: 현재 기록에서 사라지고 이전 체크포인트에는 남는다
