## 시그니처
```c
KiottySpecStatus KiottySpec_Context_forChangeRequest(KiottySpec *db, const char *crId, size_t maxBytes, char **outMarkdown);  /* 변경 요청의 영향 항목과 진입 단계 판단 근거 */
```

## 사전조건
- crId 는 존재하는 변경 요청

## 사후조건
- 변경 요청 본문, 영향 항목, 진입 단계 판단 근거를 Markdown 으로

## 에러 코드
- 없는 CR: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outMarkdown 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
