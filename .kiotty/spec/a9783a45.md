## 개요
함수 5 개를 묶은 개념 단위. 함수별 계약은 하위 항목에 있고, 여기에는 묶음 공통의 타입과 규약을 둔다.

## 하위 함수
- UI-116 KiottySpec_Context_forStep
- UI-117 KiottySpec_Context_forItem
- UI-118 KiottySpec_Context_forMilestone
- UI-119 KiottySpec_Context_forChangeRequest
- UI-120 KiottySpec_Context_rules

## 시그니처
```c
(이 묶음 고유의 타입 없음, 공통 타입은 UI-001)
```

## 사전조건
- step 은 1 ~ 10, maxBytes 0 은 기본 한도

## 사후조건
- forStep: definition.md 4 절의 "Kiotty-Spec 입력". 변경 요청으로 돌아온 단계면 마지막 기준 이후 바뀐 것과 연결된 것 위주
- 한도를 넘으면 항목은 제목만, 더 넘으면 생략 수와 개별 조회 안내 (REQ-025)
- forItem: 항목과 depth 까지의 상·하류, 관련 결정 줄. rules: 코드 작성 전 읽을 개발 규칙

## 에러 코드
- 범위 밖 step: InvalidArg
- 없는 ID: NotFound
- NULL 핸들·NULL 필수 인자는 InvalidArg, 상세는 KiottySpec_lastError

## 소유권
- 모든 Markdown 은 호출자가 KiottySpec_free
