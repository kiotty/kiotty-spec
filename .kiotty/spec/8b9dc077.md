## 시그니처
```c
KiottySpecStatus KiottySpec_ChangeRequest_setState(KiottySpec *db, KiottySpecActor actor, const char *crId, KiottySpecChangeState state, const char *note);  /* 상태 변경. Done 은 현재 체크포인트를 cpClosed 로 기록 */
```

## 사전조건
- state 는 열거값 중 하나
- note 는 NULL 가능

## 사후조건
- 상태를 바꾼다. Done 이면 현재 체크포인트가 cpClosed

## 에러 코드
- 없는 CR: NotFound
- 잘못된 state: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
