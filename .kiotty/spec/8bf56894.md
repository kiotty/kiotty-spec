## 순서
1. main 이 토큰(Windows 는 UTF-16 → UTF-8)을 받아 그룹·동사로 명령을 찾는다. 없으면 사용법 오류(2)
2. Arguments 가 나머지를 위치 인자·옵션·플래그로 나누고, 루트와 actor 를 정한다
3. DB 가 필요한 명령이면 KiottySpec_open, 끝나면 Closer 가 close
4. 명령 함수가 공개 C 함수를 부르고 output 이 JSON 또는 Markdown 으로 찍는다. 커서·문자열은 바로 해제
5. 실패는 CallError → stderr 'error: <상태>: <메시지>', 종료 코드 1

## 데이터 흐름
argv → Arguments → C 호출 → JSON/Markdown(stdout) 또는 오류(stderr)
