## 진술
AI 는 단계의 산출물을 8 종류(요구사항, 개발 규칙, 외부 인터페이스, 설계, 유닛 테스트, 시스템 테스트, E2E 테스트, 마일스톤)의 항목으로 기록한다. 항목마다 종류별 분류, 상위 항목, 제목, 정해진 틀의 본문이 있고, 고치거나 없애도 이전 체크포인트에는 남는다.

## 근거 시나리오
Step 1 에서 기능 요구사항 "덧셈" 을 만들 때 본문 틀을 받아 진술·근거 시나리오·인수 조건을 채운다. 큰 요구사항 아래에 하위 요구사항을 둔다. 필요 없어진 요구사항은 없앤다.

## 인수 조건
- 전제 조건: 빈 기록 / 행동: 요구사항 두 개를 만든다 / 기대 결과: REQ-001, REQ-002 처럼 종류별 접두어와 번호가 붙는다
- 전제 조건: 요구사항 / 행동: 설계용 분류('모듈')를 붙여 만든다 / 기대 결과: 종류에 맞지 않는 분류라는 이유로 거부
- 전제 조건: 연결이 있는 항목 / 행동: 없앤다 / 기대 결과: 현재 기록과 연결에서 사라지고, 이전 체크포인트 시점에는 남는다
- 전제 조건: 항목 여럿 / 행동: 종류·분류·상위 항목·글자로 찾는다 / 기대 결과: 조건에 맞는 항목만
- 전제 조건: 종류 하나 / 행동: 본문 틀을 요청한다 / 기대 결과: 정의서 2.2.1 절의 절 목록
- 전제 조건: 상위 요구사항 / 행동: 하위 요구사항을 그 아래 순서대로 둔다 / 기대 결과: 하위 목록이 정한 순서로 보인다
