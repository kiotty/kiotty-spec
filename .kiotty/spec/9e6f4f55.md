## 개요
함수 6 개를 묶은 개념 단위. 함수별 계약은 하위 항목에 있고, 여기에는 묶음 공통의 타입과 규약을 둔다.

## 하위 함수
- UI-104 KiottySpec_Result_record
- UI-105 KiottySpec_Result_last
- UI-106 KiottySpec_Result_listBegin
- UI-107 KiottySpec_Result_failedBegin
- UI-108 KiottySpec_Result_summary
- UI-109 KiottySpec_Result_suspectsBegin

## 시그니처
```c
typedef enum KiottySpecTestResult {
    KiottySpecTestResult_Pass = 1,           /* 통과 */
    KiottySpecTestResult_Fail                /* 실패 (코드 검사면 위반 있음) */
} KiottySpecTestResult;

typedef struct KiottySpecResult {
    const char *targetId;                    /* 테스트 ID 또는 (코드 검사) 개발 규칙 ID */
    KiottySpecTestResult result;             /* PASS / FAIL */
    const char *log;                         /* 출력. 검사 FAIL 이면 위반 위치 목록 */
    const char *cpFrom;                      /* 실행한 체크포인트 */
    int64_t runAt;                           /* unix epoch */
} KiottySpecResult;
```

## 사전조건
- targetId 는 유닛·시스템·E2E 테스트 또는 (코드 검사면) 개발 규칙

## 사후조건
- record: 대상별 이력에 PASS/FAIL 과 로그를 현재 체크포인트로 쌓는다
- last 는 가장 나중 결과, failed 는 마지막이 FAIL 인 대상, summary 는 전체·통과·실패·미실행
- suspects: 실패한 테스트 → 검증한다 → 설계 → 구현한다 → 소스 파일

## 에러 코드
- 테스트·규칙이 아닌 대상: InvalidArg
- 없는 ID·결과 없음: NotFound
- NULL 핸들·NULL 필수 인자는 InvalidArg, 상세는 KiottySpec_lastError

## 소유권
- last 의 *out 은 호출자가 KiottySpec_free
- 커서는 Cursor_end
