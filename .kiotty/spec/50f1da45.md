## 규칙
한 모듈 안의 규칙은 그 모듈(예: LinkStore 의 허용 쌍, DecisionStore 의 길이 한도)이 검사한다. 액터 권한(R-2), 확정·RELEASE·정리처럼 여러 모듈을 함께 보는 규칙은 base::Project 가 맡는다. 모듈은 생성자로 앞 모듈을 받고, Project 의 멤버 선언 순서가 초기화·의존 순서다.

## 이유
규칙의 위치를 예측할 수 있게 하고, 모듈 간 순환 의존을 막는다.

## 검사 방법
requireUser 호출이 project.cpp 에만 있는지, 각 모듈 생성자 인자가 Project 에서 자기보다 앞에 선언된 모듈뿐인지 리뷰
