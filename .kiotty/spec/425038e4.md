## 시그니처
```c
KiottySpecStatus KiottySpec_Item_setParent(KiottySpec *db, KiottySpecActor actor, const char *itemId, const char *parentIdOrNull, int32_t seq);  /* 상위 항목과 순서를 바꾼다 */
```

## 사전조건
- parentIdOrNull 은 NULL(최상위) 또는 자기 자신·자손이 아닌 현재 항목

## 사후조건
- 상위 항목과 형제 간 순서(seq)를 바꾼 새 버전을 쓴다

## 에러 코드
- 자기 자신·순환: InvalidArg
- 없는 항목·상위: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
