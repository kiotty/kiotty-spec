## 시그니처
```c
KiottySpecStatus KiottySpec_Link_add(KiottySpec *db, KiottySpecActor actor, const char *fromId, const char *toId, KiottySpecLinkType type);  /* "from 은 to 를 ~한다" 링크. 허용되지 않는 쌍이면 InvalidArg (R-11) */
```

## 사전조건
- fromId·toId 는 현재 뷰의 항목 또는 파일, 서로 다름

## 사후조건
- definition.md 3 절의 쌍(R-11)일 때만 "from 은 to 를 ~한다" 링크를 현재 라운드에 쓴다

## 에러 코드
- 허용되지 않는 쌍, 자기 자신: InvalidArg (허용 쌍 안내)
- 없는 ID: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
