## 시그니처
```c
KiottySpecStatus KiottySpec_Checkpoint_position(KiottySpec *db, KiottySpecPosition **out);  /* 지금 어느 체크포인트·단계에 있고 다음에 무엇을 할지 (오랜만에 돌아왔을 때) */
```

## 사전조건
- 없음. 체크포인트가 없어도 된다

## 사후조건
- *out 에 최근 체크포인트·단계·확정 여부·RELEASE 여부·묶이지 않은 쓰기 수·다음 단계·다음 할 일. 저장하지 않고 계산 (R-12)
- 다음 할 일 순서: 미확정 확정 → 열린 변경 요청의 가장 앞 진입 단계 → 다음 단계

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *out 는 호출자가 KiottySpec_free
