## 시그니처
```c
KiottySpecStatus KiottySpec_Link_remove(KiottySpec *db, KiottySpecActor actor, const char *fromId, const char *toId, KiottySpecLinkType type);  /* 링크 제거 */
```

## 사전조건
- 그 링크가 현재 뷰에 있음

## 사후조건
- 현재 뷰에서 뺀다. 이전 체크포인트에는 남는다

## 에러 코드
- 없는 링크: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
