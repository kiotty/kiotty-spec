## 개요
함수 3 개를 묶은 개념 단위. 함수별 계약은 하위 항목에 있고, 여기에는 묶음 공통의 타입과 규약을 둔다.

## 하위 함수
- UI-060 KiottySpec_Checkpoint_releaseCheck
- UI-061 KiottySpec_Checkpoint_release
- UI-062 KiottySpec_Checkpoint_prune

## 시그니처
```c
(이 묶음 고유의 타입 없음, 공통 타입은 UI-001)
```

## 사전조건
- release·prune 의 actor 는 User (R-2)
- prune 의 기준은 확정된 체크포인트

## 사후조건
- releaseCheck: R-10 (시스템·E2E 전부 PASS, 검사 위반 0, 열린 CR 0) 판정과 남은 목록, 기록은 그대로
- release: RELEASE 목적의 체크포인트를 만들고 확정. 이후 다음 할 일은 유지보수
- prune: 기준 이전 체크포인트와 거기에만 속한 기록을 지우고 지운 수를 준다. 기준 시점 내용은 그대로

## 에러 코드
- Ai 가 release·prune: Permission
- R-10 미충족: Precondition
- 미확정 기준 또는 기준 이전에 RELEASE: Precondition
- 없는 CP: NotFound
- NULL 핸들·NULL 필수 인자는 InvalidArg, 상세는 KiottySpec_lastError

## 소유권
- releaseCheck 의 보고서, release 의 *outId 는 호출자가 KiottySpec_free
