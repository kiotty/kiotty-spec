## 시그니처
```c
KiottySpecStatus KiottySpec_Decision_get(KiottySpec *db, KiottySpecDecisionKind kind, char **outMarkdown);  /* 현재 결정 기록 본문 */
```

## 사전조건
- kind 는 결정 기록 종류

## 사후조건
- *outMarkdown 에 현재 결정 기록 (없으면 빈 문자열)

## 에러 코드
- 모르는 kind: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outMarkdown 는 호출자가 KiottySpec_free
