## 시그니처
```c
KiottySpecStatus KiottySpec_open(const char *projectRoot, KiottySpec **out);  /* 프로젝트 루트의 .kiotty/spec.db 를 연다 (없으면 생성) */
```

## 사전조건
- projectRoot 는 존재하는 디렉토리 (UTF-8 경로)

## 사후조건
- <projectRoot>/.kiotty/spec.db 를 열고 없으면 만든다. 구버전 스키마는 올린다
- *out 에 핸들

## 에러 코드
- projectRoot 가 디렉토리가 아님, .kiotty 를 만들 수 없음: Io
- SQLite 열기 실패: Db
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *out 는 KiottySpec_close 로 닫는다
- 입력 문자열은 호출 동안만 읽는다
