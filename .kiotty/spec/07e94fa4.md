## 시그니처
```c
KiottySpecStatus KiottySpec_getPolicy(KiottySpec *db, const char *key, char **outValue);  /* 정책 조회 */
```

## 사전조건
- 없음

## 사후조건
- *outValue 에 저장된 값

## 에러 코드
- 설정되지 않은 key: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outValue 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
