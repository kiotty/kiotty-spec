## 시그니처
```c
KiottySpecStatus KiottySpec_Item_get(KiottySpec *db, const char *itemId, KiottySpecItem **out);  /* 현재 버전 조회 */
```

## 사전조건
- 없음

## 사후조건
- *out 에 현재 버전

## 에러 코드
- 현재 뷰에 없음: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *out 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
