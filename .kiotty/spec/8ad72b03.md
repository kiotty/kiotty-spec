## 시그니처
```c
KiottySpecStatus KiottySpec_Milestone_setEntryState(KiottySpec *db, KiottySpecActor actor, const char *milestoneId, const char *itemId, KiottySpecImplState state);  /* 포함 항목의 상태를 기록한다. 구현 완료면 현재 체크포인트가 implementedCp 가 된다 */
```

## 사전조건
- milestoneId 는 마일스톤, itemId 는 그 마일스톤이 포함한다 링크로 가리키는 항목

## 사후조건
- 포함 항목 상태를 기록한다. Implemented 면 현재 체크포인트가 implementedCp

## 에러 코드
- 마일스톤이 아님, 포함하지 않은 항목, 잘못된 state: InvalidArg
- 없는 ID: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
