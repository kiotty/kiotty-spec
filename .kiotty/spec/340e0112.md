## 시그니처
```c
KiottySpecStatus KiottySpec_Checkpoint_create(KiottySpec *db, KiottySpecActor actor, int32_t step, const char *note, char **outId);  /* 라운드를 마치고 현재 작업 내용을 새 체크포인트로 찍는다 */
```

## 사전조건
- step 은 1 ~ 10

## 사후조건
- 아직 묶이지 않은 쓰기를 새 체크포인트로 묶는다. ID 는 CP-#### (4 자리, 이어지는 번호)
- *outId 에 ID

## 에러 코드
- step 범위 밖: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- *outId 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
