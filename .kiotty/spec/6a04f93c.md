## 진술
사용자는 모든 시스템·E2E 테스트가 통과하고 코드 검사 위반과 열린 변경 요청이 없을 때 RELEASE 를 선언하고, 기록이 커지면 확정된 기준 이전을 지워 가볍게 유지한다.

## 근거 시나리오
1. Step 10 이 확정되면 AI 가 RELEASE 조건을 확인해 보고한다.
2. 사용자가 RELEASE 를 선언한다. 이후 문제는 이슈 변경 요청으로 들어온다.
3. 시간이 지나 기록이 커지면 사용자가 확정 체크포인트 하나를 기준으로 그 이전을 지운다.

## 인수 조건
- 전제 조건: RELEASE 조건을 모두 만족 / 행동: 사용자가 RELEASE 를 선언한다 / 기대 결과: RELEASE 체크포인트가 생기고 다음 할 일이 "유지보수" 가 된다
- 전제 조건: 조건 중 하나라도 불만족 / 행동: RELEASE 를 시도한다 / 기대 결과: 거부되고 무엇이 남았는지 목록이 보인다
