## 시그니처
```c
KiottySpecStatus KiottySpec_File_listBegin(KiottySpec *db, KiottySpecFileRole roleOr0, KiottySpecCursor **outCursor);  /* 역할별 파일 열거 (getFile) */
```

## 사전조건
- roleOr0 은 0(전체) 또는 역할

## 사후조건
- 파일 커서 (getFile)

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
