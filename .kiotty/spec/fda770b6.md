## 시그니처
```c
KiottySpecStatus KiottySpec_Context_forMilestone(KiottySpec *db, const char *milestoneId, size_t maxBytes, char **outMarkdown);  /* 마일스톤 구현에 필요한 설계·유닛 테스트·규칙·결정 줄·소스 파일 */
```

## 사전조건
- milestoneId 는 마일스톤

## 사후조건
- 포함 항목과 상태, 설계·유닛 테스트, 개발 규칙, 결정 줄, 소스 파일을 Markdown 으로

## 에러 코드
- 없는 ID: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outMarkdown 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
