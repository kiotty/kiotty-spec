## 시그니처
```c
KiottySpecStatus KiottySpec_Item_searchBegin(KiottySpec *db, const char *query, size_t limit, KiottySpecCursor **outCursor);  /* 제목·본문 전문 검색 (getItem) */
```

## 사전조건
- query 는 비어 있지 않음
- limit 0 은 기본

## 사후조건
- 제목·본문 검색 결과 커서 (getItem)

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
