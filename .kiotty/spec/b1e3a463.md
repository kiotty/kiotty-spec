## 시그니처
```c
KiottySpecStatus KiottySpec_ChangeRequest_create(KiottySpec *db, KiottySpecActor actor, KiottySpecChangeSource source, const char *body, int32_t entryStep, char **outId);  /* 변경 요청을 열고 진입 단계를 기록한다 */
```

## 사전조건
- entryStep 은 1 ~ 10, body 는 비어 있지 않음
- Issue 는 RELEASE 이후에 쓰는 것이 정의서 흐름 (검사하지 않음)

## 사후조건
- CR-### 발급, Open, 현재 체크포인트가 cpOpened
- *outId 에 ID

## 에러 코드
- 범위 밖 entryStep, 빈 body, 잘못된 source: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- *outId 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
