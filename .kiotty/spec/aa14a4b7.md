## 시그니처
```c
KiottySpecStatus KiottySpec_Checkpoint_changedItemsBegin(KiottySpec *db, const char *cpFrom, const char *cpToOrNull, KiottySpecCursor **outCursor);  /* 두 체크포인트 사이에 바뀐 항목 (getItem). cpTo 가 NULL 이면 현재까지 */
```

## 사전조건
- cpFrom 은 존재하는 체크포인트, cpToOrNull 은 NULL(현재까지) 또는 그 뒤 체크포인트

## 사후조건
- 두 시점 사이 추가·수정·삭제된 항목 커서 (getItem)

## 에러 코드
- 없는 CP: NotFound
- 형식 오류: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
