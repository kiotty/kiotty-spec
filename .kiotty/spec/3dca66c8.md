## 시그니처
```c
KiottySpecStatus KiottySpec_Result_suspectsBegin(KiottySpec *db, const char *failedTargetId, KiottySpecCursor **outCursor);  /* 실패한 테스트에서 검증한다 → 구현한다 링크를 따라 원인 후보 설계 항목·소스 파일 (getId) */
```

## 사전조건
- failedTargetId 는 테스트

## 사후조건
- 실패한 테스트 → 검증한다 → 설계 → 구현한다 → 소스 파일로 따라간 원인 후보 ID 커서 (getId)

## 에러 코드
- 없는 ID: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
