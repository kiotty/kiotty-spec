## 순서
1. 호출자가 공개 함수를 부른다 (예: KiottySpec_Item_create)
2. 경계가 guard 안에서 핸들·필수 인자·actor 를 검사한다. 위반은 InvalidArg
3. Project 의 해당 Store 메서드를 부른다. 여러 문장을 쓰면 Store 가 Savepoint 를 연다
4. 성공: Savepoint commit, 결과를 pack*/커서로 포장해 *out 에 넣고 Ok, lastError 비움
5. 실패: core::Error 가 던져지면 Savepoint 소멸자가 롤백, guard 가 상태 코드와 lastError 로 바꾼다. 그 밖의 예외는 Db

## 데이터 흐름
입력 C 문자열 → std::string 복사 → 레코드 → (pack/box) → 호출자 소유 메모리. 오류는 Error(status, message) → KiottySpecStatus + lastError
