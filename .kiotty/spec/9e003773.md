## 진술
AI 는 준비된 질의로 답할 수 없는 질문을 기록에 직접 물을 수 있다. 직접 질의는 읽기만 할 수 있고 기록을 바꿀 수 없다.

## 근거 시나리오
AI 가 "지난 세 체크포인트 동안 가장 많이 바뀐 설계는?" 처럼 미리 준비되지 않은 질문을 해야 할 때 쓴다. 실수로 기록을 망가뜨리지 않도록 쓰기는 막는다.

## 인수 조건
- 전제 조건: 기록 / 행동: 읽기 질의를 던진다 / 기대 결과: 결과 행이 JSON 으로 온다
- 전제 조건: 기록 / 행동: 기록을 지우거나 바꾸는 질의를 던진다 / 기대 결과: 거부되고 기록은 그대로다
- 전제 조건: 기록 / 행동: 기록 구조의 버전을 묻는다 / 기대 결과: 현재 버전 번호
