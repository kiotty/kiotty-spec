## 시그니처
```c
KiottySpecStatus KiottySpec_Item_getAt(KiottySpec *db, const char *itemId, const char *cpId, KiottySpecItem **out);  /* 특정 체크포인트 시점의 버전 조회 */
```

## 사전조건
- cpId 는 존재하는 체크포인트

## 사후조건
- *out 에 그 체크포인트 시점의 버전

## 에러 코드
- 그 시점에 없음, 없는 CP: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *out 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
