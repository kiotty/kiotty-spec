## 개요
함수 3 개를 묶은 개념 단위. 함수별 계약은 하위 항목에 있고, 여기에는 묶음 공통의 타입과 규약을 둔다.

## 하위 함수
- UI-043 KiottySpec_Transaction_start
- UI-044 KiottySpec_Transaction_commit
- UI-045 KiottySpec_Transaction_rollback

## 시그니처
```c
(이 묶음 고유의 타입 없음, 공통 타입은 UI-001)
```

## 사전조건
- commit·rollback 은 start 뒤에만
- 중첩 start 는 하지 않는다

## 사후조건
- start ~ commit 사이 쓰기는 모두 반영되거나, rollback 시 모두 사라진다 (REQ-023)
- 트랜잭션 밖의 단일 쓰기 함수도 각자 원자적이다

## 에러 코드
- 열린 트랜잭션 없이 commit·rollback, 또는 중첩 start: Db (SQLite 오류 그대로)
- NULL 핸들·NULL 필수 인자는 InvalidArg, 상세는 KiottySpec_lastError

## 소유권
- 반환 값 없음
