## 시그니처
```c
KiottySpecStatus KiottySpec_File_byPath(KiottySpec *db, const char *path, KiottySpecFile **out);  /* 경로로 조회 */
```

## 사전조건
- path 는 등록할 때와 같은 방식으로 정규화된다

## 사후조건
- *out 에 파일

## 에러 코드
- 등록되지 않은 경로: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *out 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
