## 시그니처
```c
KiottySpecStatus KiottySpec_Checkpoint_get(KiottySpec *db, const char *cpId, KiottySpecCheckpoint **out);  /* 체크포인트 하나 조회 */
```

## 사전조건
- cpId 는 CP-#### 형식

## 사후조건
- *out 에 체크포인트

## 에러 코드
- 형식 오류·PENDING: InvalidArg
- 없는 CP: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *out 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
