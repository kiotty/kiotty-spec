## 내용
| 경로 | 내용 | 빌드 타깃 |
| --- | --- | --- |
| include/kiotty_spec.h | 공개 C 인터페이스 (FILE-001) | kiotty_spec 의 PUBLIC include |
| src/kiotty_spec.cpp | C 경계 | kiotty_spec (정적 라이브러리) |
| src/implementation/base | 사양 모델 모듈 | kiotty_spec |
| src/implementation/core | 공용 기반 모듈 | kiotty_spec |
| app/cli | ks CLI | ks (실행 파일) |
| .kiotty/ | 프로젝트별 기록 (런타임) | - |

- 계층: C 인터페이스 → 경계 → base → core (RULE-001). 위 계층만 아래를 include 한다
- CMake 3.24+, C++20, MSVC /W4 /utf-8 또는 -Wall -Wextra -Wpedantic (RULE-010)
- 외부 의존성은 FetchContent 로 받는 SQLite amalgamation, nlohmann/json, md4c 셋뿐 (RULE-009)
- ks 는 kiotty_spec 과 nlohmann/json 만 링크하고 공개 헤더만 include 한다 (RULE-003)
