## 개요
함수 5 개를 묶은 개념 단위. 함수별 계약은 하위 항목에 있고, 여기에는 묶음 공통의 타입과 규약을 둔다.

## 하위 함수
- UI-020 KiottySpec_free
- UI-021 KiottySpec_strerror
- UI-022 KiottySpec_enumName
- UI-023 KiottySpec_enumParse
- UI-024 KiottySpec_lastError

## 시그니처
```c
typedef enum KiottySpecStatus {
    KiottySpecStatus_Ok = 0,                 /* 성공 */
    KiottySpecStatus_NotFound,               /* ID 에 해당하는 기록 없음 */
    KiottySpecStatus_InvalidArg,             /* 인자 오류. 허용되지 않는 링크 쌍, 결정 기록 길이 초과 포함 (R-7, R-11) */
    KiottySpecStatus_Confirmed,              /* 확정된 체크포인트의 내용을 바꾸려 함 (R-1) */
    KiottySpecStatus_Permission,             /* 액터 권한 부족. 예) Ai 가 체크포인트 확정 (R-2) */
    KiottySpecStatus_Precondition,           /* 확정 조건·RELEASE 조건·1:1·포함 조건 미충족 (R-3, R-4, R-5, R-10) */
    KiottySpecStatus_Conflict,               /* jsonl 가져오기 등에서 같은 ID 충돌 */
    KiottySpecStatus_WrongCursorType,        /* 커서 원소 종류와 다른 get 함수를 호출함 */
    KiottySpecStatus_Io,                     /* 파일 입출력 오류 */
    KiottySpecStatus_Db                      /* SQLite 내부 오류 */
} KiottySpecStatus;

typedef enum KiottySpecActor {
    KiottySpecActor_User = 1,                /* 사용자 */
    KiottySpecActor_Ai                       /* AI */
} KiottySpecActor;
```

## 사전조건
- 없음. 이 그룹의 함수는 DB 핸들 없이 부를 수 있다
- enumParse 의 enumType 은 헤더 주석에 나열된 13 개 이름 중 하나

## 사후조건
- 모든 공개 함수는 KiottySpecStatus 를 돌려주고 예외를 내보내지 않는다 (REQ-021)
- 실패한 호출은 같은 스레드의 lastError 를 비어 있지 않은 메시지로 바꾼다. 성공은 lastError 를 비운다
- enumParse 는 영문 이름을 받는다. enumName 은 모르는 값에 "unknown"

## 에러 코드
- enumParse: 모르는 enumType·이름이면 InvalidArg (받을 수 있는 값은 메시지에 없음 — 261104_01 #2)
- strerror·enumName·lastError·free 는 실패하지 않는다

## 소유권
- free 는 단일 레코드·문자열 out 값 하나를 해제한다. NULL 은 무시
- strerror·enumName·lastError 가 돌려주는 문자열은 라이브러리 소유, 해제하지 않는다. lastError 는 다음 호출 전까지 유효
