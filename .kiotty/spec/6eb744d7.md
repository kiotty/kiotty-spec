## 시그니처
```c
KiottySpecStatus KiottySpec_Checkpoint_diff(KiottySpec *db, const char *cpA, const char *cpB, char **outMarkdown);  /* 두 체크포인트 간 추가·수정·삭제를 Markdown 으로 */
```

## 사전조건
- cpA·cpB 는 존재하는 체크포인트

## 사후조건
- *outMarkdown 에 추가·수정·삭제 목록

## 에러 코드
- 없는 CP: NotFound
- 형식 오류: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outMarkdown 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
