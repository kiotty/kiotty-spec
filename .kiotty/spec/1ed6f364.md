## 진술
기록은 텍스트 파일로 내보내져 git 에 커밋되고, 그 파일로 기록을 그 시점 상태로 다시 만들 수 있다. 같은 기록은 항상 같은 파일로 내보내져, 바뀌지 않았으면 커밋에 변화가 생기지 않는다.

## 근거 시나리오
정의서 6 절 "저장 파일". 훅을 설치했으면 커밋 전에 자동으로 내보내고, 체크아웃·병합 뒤에 자동으로 다시 만든다. 한 사람이 관리한다는 전제이므로 서로 다른 기록을 합치는 경우는 다루지 않는다 (261104_02_backlog.md).

## 인수 조건
- 전제 조건: 기록 / 행동: 내보낸다 / 기대 결과: 종류별 텍스트 파일. 같은 기록을 두 번 내보내면 같은 파일이다
- 전제 조건: 내보낸 파일 / 행동: 빈 프로젝트에서 그 파일로 다시 만든다 / 기대 결과: 같은 기록 (다시 내보내면 같은 파일)
- 전제 조건: 훅이 설치된 저장소, 기록이 다른 두 브랜치 / 행동: 다른 브랜치로 바꾼다 / 기대 결과: 기록이 그 브랜치에 커밋된 상태로 바뀐다
- 전제 조건: 한 줄이 깨진 파일 / 행동: 다시 만든다 / 기대 결과: 어느 파일 몇 번째 줄인지 알려 주며 거부, 기록은 시도 전 그대로
