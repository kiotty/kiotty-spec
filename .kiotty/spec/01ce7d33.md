## 규칙
구현 내부의 모든 실패는 core::fail / core::require 로 core::Error(상태, 메시지)를 던진다. 공개 C 함수는 전부 guard() 로 감싸 예외를 KiottySpecStatus 와 thread_local lastError 로 바꾼다. 공개 함수 밖으로 예외를 내보내지 않는다.

## 이유
내부 코드는 오류 전파를 신경 쓰지 않고 쓸 수 있고, C 경계 밖으로 예외가 새는 정의되지 않은 동작을 막는다.
