## 시그니처
```c
KiottySpecStatus KiottySpec_Decision_getAt(KiottySpec *db, KiottySpecDecisionKind kind, const char *cpId, char **outMarkdown);  /* 특정 체크포인트 시점의 결정 기록 */
```

## 사전조건
- cpId 는 존재하는 체크포인트

## 사후조건
- *outMarkdown 에 그 시점의 결정 기록

## 에러 코드
- 없는 CP: NotFound
- 모르는 kind: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outMarkdown 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
