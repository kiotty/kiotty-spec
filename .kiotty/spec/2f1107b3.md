## 시그니처
```c
KiottySpecStatus KiottySpec_ChangeRequest_setEntryStep(KiottySpec *db, KiottySpecActor actor, const char *crId, int32_t entryStep);  /* 영향 분석 뒤 진입 단계를 정정한다 */
```

## 사전조건
- entryStep 은 1 ~ 10

## 사후조건
- 진입 단계를 바꾼다. 현재 위치 안내도 새 단계부터

## 에러 코드
- 범위 밖 entryStep: InvalidArg
- 없는 CR: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
