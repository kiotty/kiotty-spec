## 시그니처
```c
KiottySpecStatus KiottySpec_Transaction_start(KiottySpec *db);  /* 여러 쓰기를 원자적으로 묶기 시작 */
```

## 사전조건
- 열린 트랜잭션이 없음

## 사후조건
- 이후 쓰기를 하나로 묶는다 (BEGIN IMMEDIATE, REQ-023)

## 에러 코드
- 이미 열린 트랜잭션, 다른 쓰기 잠금: Db
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- 돌려받아 해제할 메모리 없음
