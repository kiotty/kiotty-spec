## 시그니처
```c
KiottySpecStatus KiottySpec_Context_whereAmI(KiottySpec *db, size_t maxBytes, char **outMarkdown);  /* 현재 위치, 지나온 단계, 다음 할 일, 마지막 라운드에서 바뀐 것을 한 페이지로 (재개용) */
```

## 사전조건
- maxBytes 0 은 기본 한도

## 사후조건
- 현재 위치·지나온 단계·다음 할 일·마지막 라운드에서 바뀐 것·확정 조건 검사를 Markdown 한 페이지로

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outMarkdown 는 호출자가 KiottySpec_free
