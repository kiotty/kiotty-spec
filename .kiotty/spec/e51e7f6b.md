## 전제 조건
- 임시 프로젝트 디렉토리에 열린 프로젝트 (RULE-011)
- 설계 항목 D 하나와 마일스톤 M 하나를 만들고, M 이 D 를 covers 링크로 포함한다
- 아직 setEntryState 를 부르지 않았다

## 행동
1. entries(M) 를 읽는다
2. setEntryState(M, D, implemented) 를 부르고 entries(M) 를 읽는다
3. 체크포인트를 찍은 뒤 D 의 본문을 update 하고 entries(M) 를 읽는다
4. setEntryState(M, D, implemented) 를 다시 부르고 entries(M) 를 읽는다

## 기대 결과
1. D 의 상태는 not_implemented, implementedCp 없음
2. D 의 상태는 implemented, implementedCp 는 현재 라운드(PENDING)
3. D 의 상태는 needs_change (구현 완료 시점의 쓰기 순번보다 D 의 wseq 가 큼, R-6). 저장된 상태 자체는 바뀌지 않음
4. D 의 상태는 다시 implemented
