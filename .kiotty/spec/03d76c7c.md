## 개요
함수 7 개를 묶은 개념 단위. 함수별 계약은 하위 항목에 있고, 여기에는 묶음 공통의 타입과 규약을 둔다.

## 하위 함수
- UI-036 KiottySpec_open
- UI-037 KiottySpec_close
- UI-038 KiottySpec_init
- UI-039 KiottySpec_setPolicy
- UI-040 KiottySpec_getPolicy
- UI-041 KiottySpec_Schema_version
- UI-042 KiottySpec_Schema_migrate

## 시그니처
```c
typedef struct KiottySpec       KiottySpec;        /* 열린 프로젝트 DB */
```

## 사전조건
- open 의 projectRoot 는 존재하는 디렉토리 (UTF-8 경로)
- init 의 installGitHooks=true 는 git 저장소일 때만
- setPolicy 의 key 는 decision_max_line, decision_max_concerns (다른 키도 저장은 되지만 쓰이지 않음)

## 사후조건
- open: <projectRoot>/.kiotty/spec.db 를 열고 없으면 만든다. 구버전 스키마는 현재 버전으로 올린다
- init: 프로젝트 메타데이터 기록, .gitignore 에 작업용 DB 줄을 중복 없이 추가, 선택 시 pre-commit·post-merge 훅 설치. 다시 불러도 기존 기록 유지
- setPolicy 뒤의 결정 기록 검사는 새 한도를 쓴다
- Schema_version 은 현재 스키마 버전, Schema_migrate 는 라이브러리 버전까지 올린다

## 에러 코드
- git 저장소가 아닌데 훅 설치 요청: Precondition
- 파일·디렉토리 접근 실패: Io, SQLite 실패: Db
- 빈 정책 key: InvalidArg, getPolicy 에서 설정되지 않은 key: NotFound
- NULL 핸들·NULL 필수 인자는 InvalidArg, 상세는 KiottySpec_lastError

## 소유권
- open 의 *out 은 close 로만 닫는다
- getPolicy 의 *outValue 는 호출자가 KiottySpec_free
