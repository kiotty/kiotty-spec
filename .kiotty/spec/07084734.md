## 시그니처
```c
KiottySpecStatus KiottySpec_Item_template(KiottySpecItemKind kind, KiottySpecItemCategory category, char **outMarkdown);  /* 종류별 본문 틀(definition.md 2.2.1)을 돌려준다 */
```

## 사전조건
- category 는 kind 에 맞는 분류 또는 None

## 사후조건
- *outMarkdown 에 definition.md 2.2.1 의 절 목록 (DB 없이 부를 수 있음)

## 에러 코드
- 모르는 kind·맞지 않는 category: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outMarkdown 는 호출자가 KiottySpec_free
