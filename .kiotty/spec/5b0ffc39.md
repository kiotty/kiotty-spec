## 시그니처
```c
KiottySpecStatus KiottySpec_Link_scopeOf(KiottySpec *db, const char *designOrFileId, KiottySpecScope *outScope, KiottySpecCursor **outAffectedModules);  /* 수정이 의존한다 링크로 다른 모듈에 닿는지 판정하고 닿는 모듈을 돌려준다 (getItem) */
```

## 사전조건
- 대상은 설계 항목 또는 소스 파일
- outAffectedModules 는 NULL 가능

## 사후조건
- *outScope 에 의존한다 링크로 다른 모듈에 닿으면 InterModule, 아니면 IntraModule
- *outAffectedModules 에 닿는 모듈 (getItem)

## 에러 코드
- 없는 ID: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outAffectedModules 커서는 호출자가 KiottySpec_Cursor_end
- 입력 문자열은 호출 동안만 읽는다
