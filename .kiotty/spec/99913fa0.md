## 시그니처
```c
KiottySpecStatus KiottySpec_Checkpoint_listBegin(KiottySpec *db, int32_t stepOr0, KiottySpecCursor **outCursor);  /* 체크포인트 목록 (getCheckpoint) */
```

## 사전조건
- stepOr0 은 0(전체) 또는 1 ~ 10

## 사후조건
- 체크포인트 목록 커서 (getCheckpoint), 오래된 순

## 에러 코드
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outCursor 커서는 호출자가 KiottySpec_Cursor_end
