## 시그니처
```c
KiottySpecStatus KiottySpec_Item_update(KiottySpec *db, KiottySpecActor actor, const char *itemId, const char *title, const char *body);  /* 제목·본문을 바꾼다. 새 버전은 현재 체크포인트에 속한다 */
```

## 사전조건
- 항목이 현재 뷰에 있음
- title·body 중 NULL 은 바꾸지 않음

## 사후조건
- 새 버전을 현재 라운드에 쓴다. 이전 체크포인트 시점은 그대로 (R-1)

## 에러 코드
- 빈 title: InvalidArg
- 없는 항목: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음
- 입력 문자열은 호출 동안만 읽는다
