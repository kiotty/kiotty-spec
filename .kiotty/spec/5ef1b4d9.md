## 진술
사용자는 종류별 문서(요구사항서, 설계서, 테스트 계획서, 개발 계획서)와 추적 보고서를 Markdown 으로 뽑아 검토하고, 정해진 틀로 쓴 Markdown 문서를 항목으로 한꺼번에 가져올 수 있다.

## 근거 시나리오
사용자가 요구사항 검토 회의 전에 요구사항서를 뽑는다. 기존에 문서로만 있던 요구사항을 처음 들여올 때 문서를 그대로 가져온다.

## 인수 조건
- 전제 조건: 요구사항 여럿 / 행동: 요구사항서를 뽑는다 / 기대 결과: 항목마다 "ID [분류] 제목", 연결 요약, 본문
- 전제 조건: 기록 / 행동: 추적 보고서를 뽑는다 / 기대 결과: 추적표와 불일치 검사 보고서
- 전제 조건: "## [분류] 제목" 절이 두 개인 문서 / 행동: 요구사항으로 가져온다 / 기대 결과: 요구사항 둘이 생기고 만든 ID 목록이 보인다
