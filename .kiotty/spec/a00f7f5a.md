## 시그니처
```c
KiottySpecStatus KiottySpec_ChangeRequest_get(KiottySpec *db, const char *crId, KiottySpecChangeRequest **out);  /* 변경 요청 하나 조회 */
```

## 사전조건
- 없음

## 사후조건
- *out 에 변경 요청

## 에러 코드
- 없는 CR: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *out 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
