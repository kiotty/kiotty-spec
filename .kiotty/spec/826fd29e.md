## 시그니처
```c
KiottySpecStatus KiottySpec_Context_forStep(KiottySpec *db, int32_t step, size_t maxBytes, char **outMarkdown);  /* definition.md 4 절 표의 "Kiotty-Spec 입력" 을 그 단계에 맞게 묶는다. 영향 항목이 있으면 그것만 */
```

## 사전조건
- step 은 1 ~ 10, maxBytes 0 은 기본 한도

## 사후조건
- definition.md 4 절의 "Kiotty-Spec 입력" 을 Markdown 으로. 변경 요청으로 돌아온 단계면 바뀐 것과 연결된 것 위주
- 한도를 넘으면 항목은 제목만, 더 넘으면 생략 수와 개별 조회 안내 (REQ-025)

## 에러 코드
- step 범위 밖: InvalidArg
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outMarkdown 는 호출자가 KiottySpec_free
