## 시그니처
```c
KiottySpecStatus KiottySpec_Query_readonly(KiottySpec *db, const char *sql, char **outJson);  /* 읽기 전용 SQL (예외적 질의용) */
```

## 사전조건
- sql 은 읽기 전용 SQL 한 문장

## 사후조건
- *outJson 에 결과 행 JSON 배열. 기록은 바뀌지 않는다

## 에러 코드
- 읽기 전용이 아닌 SQL: Permission
- SQL 문법 오류: Db
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outJson 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
