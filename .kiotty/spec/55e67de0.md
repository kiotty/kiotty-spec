## 시그니처
```c
KiottySpecStatus KiottySpec_Checkpoint_prune(KiottySpec *db, KiottySpecActor actor, const char *baseCpId, size_t *outRemoved);  /* 기준 체크포인트 이전 기록을 모두 지운다 (Compaction). 최신 확정·RELEASE 는 기준으로만 가능 */
```

## 사전조건
- actor 는 User (R-2)
- baseCpId 는 확정된 체크포인트, 그 이전에 RELEASE 가 없음

## 사후조건
- 기준 이전 체크포인트와 거기에만 속한 기록을 지운다. 기준 시점 내용은 그대로
- *outRemoved 에 지운 수

## 에러 코드
- Ai: Permission
- 미확정 기준, 이전에 RELEASE: Precondition
- PENDING 지정: InvalidArg
- 없는 CP: NotFound
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)
- 잘못된 actor 값: InvalidArg

## 소유권
- 돌려받아 해제할 메모리 없음 (out 값은 호출자 변수에 복사)
- 입력 문자열은 호출 동안만 읽는다
