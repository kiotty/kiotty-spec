## 규칙
app/cli 는 include/kiotty_spec.h 만 쓰고 src/implementation 을 include 하지 않는다. 명령은 C 함수와 1:1 로 대응한다 (`ks <그룹> <동사>` == KiottySpec_<그룹>_<동사>).

## 이유
CLI 가 곧 C 인터페이스의 첫 사용자이자 E2E 경로가 되고, 두 인터페이스가 어긋나지 않는다.

## 검사 방법
app/cli 의 #include 에 implementation/ 이 없는지 grep, commands.cpp 의 명령 목록과 헤더의 함수 목록 대조
