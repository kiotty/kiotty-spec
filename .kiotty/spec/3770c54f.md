## 시그니처
```c
const char *KiottySpec_enumName(const char *enumType, int value);  /* 열거값의 이름. enumType 예) "ItemKind" → 1 은 "requirement". 모르면 "unknown" */
```

## 사전조건
- enumType 은 enumParse 와 같은 13 개 이름 중 하나

## 사후조건
- 영문 이름(예: ItemKind 1 → "requirement"). 모르는 타입·값은 "unknown"

## 에러 코드
- 없음 (const char * 를 돌려주며 실패하지 않는다)

## 소유권
- 돌려주는 문자열은 라이브러리 소유, 해제하지 않는다
- 입력 문자열은 호출 동안만 읽는다
