## 시그니처
```c
KiottySpecStatus KiottySpec_Import_jsonl(KiottySpec *db, const char *dir, bool merge, char **outConflictReport);  /* jsonl 로 DB 를 재생성하거나 병합한다. 같은 ID 충돌은 뒤 체크포인트를 택하고 보고. post-merge 훅 */
```

## 사전조건
- dir 은 Export_jsonl 이 쓴 디렉토리
- outConflictReport 는 NULL 가능

## 사후조건
- merge=false: jsonl 로 DB 를 다시 만든다 (post-merge 훅)
- merge=true: 같은 ID 는 기존 행 유지 후 *outConflictReport 로 보고 (헤더 주석과 다름 — 261104_02 #4, 병합은 요구하지 않음)

## 에러 코드
- 파일 읽기 실패: Io
- jsonl 파싱 실패: InvalidArg (파일·행 번호)
- NULL 핸들·NULL 필수 인자: InvalidArg (상세는 KiottySpec_lastError)

## 소유권
- *outConflictReport 는 호출자가 KiottySpec_free
- 입력 문자열은 호출 동안만 읽는다
