## 규칙
문자열은 UTF-8 std::string 으로 다루고, 경로는 std::filesystem::path 로 받아 core::pathToUtf8 로만 바꾼다. 내부 레코드(core::*Record)는 문자열을 직접 소유하고, C 구조체 변환은 cursor.h 가 한다. 커서 원소 포인터는 커서가, 단일 결과는 호출자가 KiottySpec_free 로 해제한다.

## 이유
Windows 와 POSIX 의 경로·인코딩 차이를 한 곳에 가두고, C 소유권 규칙을 한 곳에서 지킨다.

## 검사 방법
path.string() / u8string() 직접 사용과 malloc/new 로 만든 C 문자열 반환을 grep
